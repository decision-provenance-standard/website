Reference Files

About the reference files (release 5.2.0): what they are and where they are.

The Standard does not depend on the reference files. They are machine-readable files you may consult, published separately under the MIT License. The Standard is the normative text; where the text and the files differ, the text governs.

What they are

The reference files provide JSON schemas for the Charter, decision records and the disclosure block, the state machines, the list of conformance signals, the contract for a reporter that reads those signals, and a test plan. They are files to build against, not the Standard itself.

Published: reference release 5.2.0, paired with version 1.3 of the text, is live at /standard/v5.0/. The folder keeps its v5.0 name so existing links keep working. Earlier releases stay recoverable in the standard repository: 5.1.2, paired with version 1.2, at the tag ref-5.1.2; 5.1.1, paired with version 1.1, at the tag ref-5.1.1; and 5.1.0, paired with rev. 8, at the tag rev8-published. Its source, and corrections to it, are at github.com/decision-provenance-standard/standard.

Where the files are

  • standard/v5.0/ — root of reference release 5.2.0
  • standard/v5.0/schemas/ — Charter, decision-record and disclosure JSON schemas
  • standard/v5.0/mode-drift/layer-4-attestation.schema.json — Layer 4 attestation schema
  • standard/v5.0/README.md — overview of the files

The JSON schemas are also served at the addresses their own $id fields name: /schemas/v5.0/charter.schema.json, /schemas/v5.0/decision-record.schema.json, /schemas/v5.0/article-50-disclosure-metadata.json and /schemas/v5.0/layer-4-attestation.schema.json. The attestation schema is also at /schemas/mode-drift/layer-4-attestation.schema.json, the address the decision-record schema's reference to it leads to. So a validator that fetches referenced schemas over the web can find each one. The files themselves are unchanged, so known defect KD-01 stays open in the standard repository.

To start implementing, read Companion C — Implementation Guidance alongside these files. Everything is also in the downloads.
